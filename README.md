# 冰箱灵感 · AI 食谱助手
Next.js 项目，无需 API 密钥。食谱来自内置数据库（12 道），采用食材匹配率排序及菜系、偏好筛选，不是实时 AI 生成。收藏、冰箱和菜单保存在当前浏览器。购物清单按菜单和人数估算，需核对实际库存。图片识别已移除。
部署：将 ZIP 内 app 文件夹及根目录文件上传至原 GitHub 仓库并提交，Vercel 自动部署。开发：npm install && npm run dev。

## 浏览器 AI
首次使用在支持 WebGPU 的 Chrome/Edge 中点击启动 AI，模型从模型托管服务下载并由浏览器缓存。无需 API 密钥。模型输出为独立文本菜谱；原有收藏与菜单仍使用本地菜谱库。AI 不可用时自动使用本地推荐。部署后应在演示电脑上提前测试。尚未完成实际 WebGPU 推理测试。
